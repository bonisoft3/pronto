# Neutral Specimen Sheet

The idioms carry a deliberate quiet paper-and-ink palette so attention stays on
each state machine rather than chrome ornament. Every stylesheet names semantic
roles (`--accent`, `--surface-muted`, `--secondary`) and structural rungs
(`--sp-*`, `--r-*`, `--type-*`), never a literal, so both appearances resolve
from `DESIGN.md` and the literal lint has nothing to excuse.
