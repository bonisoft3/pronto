# Acceptance

- [ ] Pressing + then − returns the counter to where it was. {#accept-count}
- [ ] An added task appears at the top, survives a reload, and is struck through once done. {#accept-todo}
- [ ] Pressing the centre light of the starting plus flips five lights, counts one move, and leaves four lit. {#accept-grid}
- [ ] A started timer counts one per second until paused, and the same seed rolls the same faces. {#accept-timer}
